# Contributing

Experimental and unmaintained. No guaranteed review, response or maintenance commitment. First-party code and tests are MIT licensed. Independent forks are welcome; preserve third-party notices.

Use a new venv with the locked test requirements and run backend/web regressions. Keep data synthetic, changes focused and private paths/keys/runtime output out of source. Matching changes need model regressions; calendar/plan changes need API and rendered browser checks. Native clients and live provider research are outside this candidate.
