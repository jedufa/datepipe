# Synthetic demonstration data

Every record here was independently hand-authored for this public-source candidate. People, venues, ideas, events and schedules are fictional. Geographic city names are labels; population zero is a placeholder, not a statistic. All venue URLs use the reserved `.invalid` domain. There are no original couple records, seed plans, research descriptions, source catalogs or scraped data.

Use these examples only to exercise planning and persistence. Verify real places and dates yourself before making a plan. The five-city demo is not a top-100 Austrian city dataset despite the compatibility filename.
